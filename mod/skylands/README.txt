Skylands 0.1 - Borderlands 2 played as Skyrim's Dragonborn

Needs: Borderlands 2 (Steam, Windows) and The Elder Scrolls V: Skyrim Special Edition installed.
Melty installs and starts everything; press Play.

- Skyrim's 18 skills, perk trees and races are read from YOUR Skyrim install while you play.
- Class skill trees and the class action skill are replaced.
- Action skill key (F): Unrelenting Force. Fus at level 1, Ro at Dragonborn level 5, Dah at 10.
- K: Skyrim skills and perks menu (the Skills tab opens it too).
- Single player. Progress is stored in each Borderlands character's save.

Log: Binaries/Win32/Plugins/unrealsdk.log (lines start with [Skylands]).
